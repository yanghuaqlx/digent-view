# Digent View

> **你的 Obsidian 笔记库，就是一个数智体的大脑。**
>
> 每一篇笔记是一个神经元，每一条 `[[wikilink]]` 是一条神经突触。Digent View 将这座大脑以三维形态呈现，让你看见自己的认知结构。

---

## 什么是数智体（Digent）

数智体（Digent），是 AI 时代的新生命单元。它由真实的人、组织或知识体系，通过 AI 持续蒸馏形成——不仅继承知识与技能，还继承思维方式、行为风格、长期记忆和价值判断。

> Agent 关注的是"把事情做完"，数智体关注的是"把一个人的认知、经验、人格、决策方式沉淀下来，并持续存在"。
>
> ——《数智体白皮书 V1.0》

数智体的六个核心要素：**智**（持续推理）、**忆**（本源记忆）、**魂**（精神内核）、**技**（专业能力）、**行**（自主执行）、**长**（持续成长）。

Digent View 关注的是其中最基础的一层——**忆**：你长年积累的知识、经验与认知轨迹，如何被组织、被看见、被理解。

## 为什么是 3D

人脑不是平面的。你的知识体系也不是。

在二维图谱里，节点被压扁在同一平面上，密集区域糊成一团，结构层次被抹平。而在三维空间里：

- **深度即层次**——顶层文件夹是脑叶，子文件夹是脑回，单篇笔记是神经元
- **距离即关联**——链接越多的节点引力越强，自然聚集成认知核心区
- **空间即记忆**——你在三维空间中的位置感知，映射为对知识结构的直觉理解

Digent View 用力导向算法模拟神经元之间的吸引与排斥，让你的笔记库自然生长成一座有结构、有层次、有核心的大脑形态。

## 核心功能

### 3D 认知图谱

- **力导向布局**——Web Worker 力学模拟，3000+ 笔记 / 20000+ 链接流畅渲染
- **极简暗色画风**——无背景层、无辉光，纯净深空，专注认知结构本身
- **电影感镜头**——点节点飞入环绕、闲置自动漂移、开场从中心绽放整座星系的创世动画
- **文件夹配色**——每个顶层文件夹对应一种颜色，同时充当过滤图例
- **Markdown 与 Canvas 同图**——`.md` 笔记和 `.canvas` 画布都进入图谱

### 统计面板

实时显示你大脑的规模：
- **笔记数**——你的神经元数量
- **链接数**——你的突触连接数
- **字数**——你的认知语料总量（智能清洗 frontmatter、代码块、格式标记后统计）

### Noda VR 导出

一键将 3D 图谱导出为 CSV，直接导入 [Noda](https://nodavr.io)（Quest 3 VR），**走进你自己数智体的大脑**。

导出内容：
- **节点（神经元）**：UUID、3D 坐标、颜色、形状、大小（按突触数平方根增长，封顶 20）、正文摘要（前 200 字，清洗格式）
- **连线（突触）**：继承源神经元颜色、UUID 关联

在 VR 中，你不再是从外面看一座图谱，而是站在自己数智体的认知空间内部，四周是你的知识星系。

## 安装

### 手动安装

1. 下载 `main.js`、`manifest.json`、`styles.css`
2. 将三个文件放入 `<你的库>/.obsidian/plugins/digent-view/`
3. 打开 Obsidian → 设置 → 第三方插件 → 启用 Digent View

### 从 Release 安装

从 [Releases](https://github.com/yanghuaqlx/digent-view/releases) 下载 `digent-view-v0.1.0.zip`，解压到插件目录即可。

## 使用

点击左侧栏的 **大脑图标** 🧠，或运行命令 `Open galaxy view`。

### 操作指南

| 操作 | 效果 |
|------|------|
| 点击节点 | 飞入并环绕该节点 |
| 搜索 | 模糊搜索飞向任意笔记 |
| 回中心 | 重置视角到图谱中心 |
| NODA | 导出 CSV 供 Noda VR 使用 |
| WASD / Q / E | 自由飞行 |
| 右键拖动 | 平移视角 |
| F / R / ESC | 快捷键 |

### Noda VR 使用流程

1. 在 Digent View 中点击「NODA」按钮，生成 CSV 文件
2. 将 CSV 传输到 Quest 3 设备
3. 在 Noda 中导入 CSV
4. 戴上头显，走进你的数智体大脑

## 隐私

无任何网络请求、无遥测。插件仅读取你 Obsidian 库的链接图谱，不发送任何数据到任何服务器。
